# MOTOATLAS Road v1.0 (Repositório Guiador / Estrada)

Aplicação complementar ultraleve desenhada para utilização em **modo horizontal (landscape)** no guiador da mota.

## Fluxo de Trabalho
1. **Antes de Arrancar (`☁️ Sync`):** Descarrega apenas a viagem ativa publicada pelo **MOTOATLAS Studio** (através do código curto na Supabase, ex.: `ANDALUZIA-26`, ou importando o ficheiro `.motoatlas.json`).
2. **Na Estrada (`🧭 Cockpit` & `⛽ Registar`):**
   * Funciona **100% offline** em memória local.
   * Botões grandes próprios para luvas, modo Dia/Noite de alto contraste, marcação de paragens concluídas, partilha rápida de coordenadas GPS com o grupo e registo de abastecimentos/despesas.
3. **No Final da Viagem (`☁️ Sync`):** Carrega em **🚀 Enviar Registos para o Studio** para devolver as despesas, litros abastecidos e odómetro atualizado ao computador.
