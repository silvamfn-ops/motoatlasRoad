# MOTOATLAS Road v1.4.2 — Navegação Inteligente para iPhone 7 Plus

- **Botão direto `▶️ Iniciar Aqui` em cada paragem do Roadbook:** Com um único toque (calibrado para luvas), marca os pontos anteriores como concluídos, ativa o GPS em tempo real, recalcula o traçado e as manobras Turn-by-Turn a partir dessa paragem e anuncia o arranque por voz PT-PT.
- **Cache atualizada (`motoatlas-road-v1.4.2-cache`):** Substituição imediata no iOS Safari.
